# 도를 아십니까? — 교주 시뮬레이터

귀엽고 수상한 캐릭터가 되어 한국의 평범한 거리에서 시민 NPC에게 황당한 멘트를 던지고, 신도를 줄줄이 달고 다니며 교주로 성장하는 **3D 로우폴리 실시간 멀티플레이 풍자 웹게임**입니다. 설치·회원가입 없이 링크만 열면 바로 거리에 섭니다.

> 이 게임의 모든 교단·인물·교리는 허구이며 풍자 코미디입니다. 실존 종교·단체·인물과 무관하고, 실제 포교·금전 요구·개인정보 수집을 하지 않습니다. 웃음거리는 언제나 교주(플레이어) 자신입니다.

## 바로 실행

```bash
npm ci
npm run build
npm start            # http://localhost:8787  (브라우저 두 개로 열면 서로 보입니다)
```

개발 모드는 `npm run dev` (서버 8787 + Vite 5173).

## 무엇을 할 수 있나

- **길거리 포교** — 시민에게 다가가 [말 걸기] → 멘트 4개 중 선택 → 합류 / "더 들어볼게요" / 거절 / 무시 / 전력 질주로 도망. 결과는 확률과 시민의 가상 성격(개그 상성)으로만 정해집니다. 멘트 110개, 시민 유형 28종(길고양이 포함).
- **신도 행렬** — 합류한 시민은 한동안 줄지어 따라다니고, 교주가 춤추면 순서대로 따라 춥니다.
- **6단계 직급** — 수상한 행인 → 길거리 전도사 → 열정적인 포교왕 → 신흥 교단장 → 대교주 → 우주급 절대교주. 오를 때마다 복장·모자·동작·멘트가 열립니다(핵심 행동은 처음부터 전부 가능).
- **나만의 교단** — 이름·색·엠블럼·칭호를 정해 창설. 방 안 교단 순위표.
- **실제 이용자와** — 이름표로 서로 보이고, 교단 가입 제안(상대가 수락해야만 가입, 거절·차단 가능), 1대1 포교 배틀(서로 동의해야 시작), 인사·따라 하기, 정해진 말풍선.
- **단상** — "오늘의 계시"(주변 시민이 반응), 구호를 주고받는 집단 설교 이벤트.
- **가상 헌금함** — 신도가 터무니없는 잡동사니를 내놓습니다. 헌납품 123종 도감. 전부 가상이며 결제가 없습니다.
- **돌발 이벤트** — 호루라기를 문 단속반에게 쫓기기, "저도 사실 교주입니다" 라이벌과 기싸움.
- **업적·일일 수행·칭호**, **교주 임명장 / 오늘의 포교 결산 / 거절 짤** 이미지 저장·공유(세로 1080×1920).
- PC(WASD·마우스)와 모바일(가상 조이스틱·탭 이동) 모두 지원.

## 멀티플레이에 대해 정직하게

- 방 기반입니다. 기본은 **방 3개 × 정원 20명**이고, 접속하면 여유 있는 방으로 자동 입장합니다. 방이 가득 차면 다른 방을 안내하고, 전부 차면 대기 화면에서 자리가 날 때까지 자동으로 다시 시도합니다.
- **실제 접속자(👤)와 NPC(🤖)는 항상 따로 셉니다.** NPC는 서버가 움직이는 가상 시민이며 접속자처럼 꾸미지 않습니다.
- 위치·동작·포교 결과·신도는 서버가 판정해 같은 방 사람들에게만 보냅니다. 연결이 끊기거나 서버가 재시작되면 자동으로 다시 붙습니다.
- 수용 인원은 **측정한 만큼만** 말합니다 → [`docs/LOADTEST.md`](docs/LOADTEST.md). (요약: 한 대의 4 vCPU 기계에서 프로세스 1개로 방 100개 × 봇 20명까지 무탈락. 실제 휴대폰·실제 인터넷에서는 재지 않았습니다.)

| | PC | 모바일 |

| 동작 | 숫자 1~8 (8 = 도망가기) | [이모트] [도망] 버튼 |

## 검증

```bash
npm run typecheck      # 클라이언트·서버 타입 검사
npm test               # 단위 테스트(서버 규칙, 프로토콜, NPC 시뮬, 콘텐츠 금지어·확률 균형 등)
npm run build && npm run test:e2e        # 브라우저 2개(PC+모바일)로 접속·이동·동기화·퇴장·재접속 확인
node tests/e2e/cult.cjs                  # 기능별: cult, podium, battle, achievements, share, onboarding, events
npm run loadtest -- --url ws://localhost:8787 --rooms 3 --bots 20 --seconds 45
```

E2E 는 Playwright(Chromium)가 필요합니다: `npm i -D playwright && npx playwright install chromium`.

`npm run test:e2e` 가 확인하는 것: 별도 절차 없이 입장 · 같은 방에서 서로 보임 · PC 키보드 이동과 모바일 터치 이동이 상대 화면에 반영 · 동작 동기화 · NPC 포교와 신도 증가 · 퇴장 시 사라짐 · 재접속 시 진행도 유지 · 끊김/서버 재시작 후 자동 재연결 · 중복 접속 처리 · 방 목록의 접속자/NPC 구분.

## 구조

```
shared/    클라·서버 공용: 프로토콜(JSON 이벤트 + 바이너리 위치), 월드 데이터, 콘텐츠, 규칙(포교 판정·이름 필터)
server/
  core/    전송 계층과 무관한 방 로직: Room, NPC 시뮬, 기능 시스템(교단·단상·배틀·헌금함·업적·단속반·기싸움)
  node/    Node 어댑터: HTTP(정적 파일, /api/rooms, /healthz) + WebSocket
worker/    Cloudflare Workers + Durable Objects 어댑터(같은 core 를 사용)
client/    Three.js 클라이언트. 그래픽·소리 전부 코드로 생성(외부 모델·이미지·음원 없음)
tests/     단위(vitest) · E2E(Playwright)
tools/     부하 테스트 봇, 프로토콜 탐침, NPC 시뮬 추적
docs/      설계·배포·부하 측정·조사 문서
```

## 알아 둘 한계

- 진행도는 계정이 아니라 **브라우저에 서명된 채로** 저장됩니다. 기기를 바꾸거나 브라우저 데이터를 지우면 이어지지 않습니다.
- 화면 성능은 헤드리스 Chromium(소프트웨어 렌더링)에서만 확인했습니다. 실제 휴대폰·인앱 브라우저(인스타그램·카카오톡)에서의 동작과 프레임은 올린 뒤 직접 확인해야 합니다.
- 효과음은 합성음이며 수치로만 검증했습니다(사람이 들어 보고 조정하지는 않았습니다).
- 이름 필터(욕설·실존 단체명)는 완벽하지 않으며 운영하면서 보강해야 합니다.
- 방을 여러 서버에 나눠 주는 분배기는 아직 없습니다(프로세스 1개 기준).
