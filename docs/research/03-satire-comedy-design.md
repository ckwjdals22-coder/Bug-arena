# 03. 풍자·코미디 게임 디자인과 "도를 아십니까" 밈 문화, 그리고 가드레일

- 조사일: 2026-11-26
- 대상 게임: "도를 아십니까? — 교주 시뮬레이터" (3D 로우폴리 실시간 멀티 풍자 웹게임)
- 조사 방법: 웹 검색 + 원문 열람(WebFetch, curl). 현재 저장소의 콘텐츠 스키마(`shared/content/*.ts`, `shared/rules/*.ts`)도 읽고 거기에 맞춰 개그 데이터를 썼다. 저장소 파일은 수정하지 않았다.
- 표기 규칙: **[확인]** = 원문에서 읽음 / **[요약]** = 검색 결과 요약으로만 봄 / **[추론]** = 근거에서 내가 끌어낸 설계 판단 / **[상식]** = 이번 조사에서 원문 확인을 못 한 일반 지식 / **확인 못함** = 근거를 못 찾음
- 4장의 개그 콘텐츠(대사, 계시, 물건, 업적)는 전부 이 문서를 위해 새로 쓴 오리지널이다. 실존 브랜드, 인물, 종교 용어는 넣지 않았다.

---

## 0. 한 페이지 요약

1. **코미디 게임의 웃음은 대사가 아니라 구조에서 나온다.** 조사한 게임들이 공통으로 쓰는 구조는 "평범한 세계 + 혼자만 이상한 주인공"(Untitled Goose Game), "실패가 곧 볼거리"(Fall Guys, Peak, Human: Fall Flat), "플레이어가 셋업을 고르고 게임이 펀치라인을 친다"(Astrologaster), "반복해서 기대를 만든 뒤 배신한다"(What the Golf)이다.
2. **우리 게임에서 웃음거리는 항상 교주(플레이어)여야 한다.** 시민 NPC는 "그냥 하루를 보내려는 평범한 사람"이고 정색하는 쪽이다. 이 한 줄이 코미디 품질과 윤리 가드레일을 동시에 해결한다. Life of Brian 제작진의 방어 논리("신앙이 아니라 사람들의 행동을 놀린다")와 같은 구조다.
3. **가장 싸고 효과 큰 메커닉은 "예능 자막"이다.** 서버는 이벤트 키만 보내고, 클라이언트가 궁서체 자막을 띄운다. 물리 엔진 없이도 모든 결과를 펀치라인으로 바꾸고, 그대로 스크린샷 소재가 된다.
4. **실제 길거리 포교의 "다음 단계"는 절대 재현하지 않는다.** 보도에 나온 실제 흐름은 칭찬으로 말 걸기 → 신상 질문 → 카페로 이동 → 조상·제사 언급 → 돈 요구 → 합숙 장소다. 우리 게임은 첫 문장(밈으로 굳은 오프닝)만 빌리고, 같은 문장 안에서 엉뚱한 소재로 꺾는다. 플레이어가 돈·연락처·이동을 요구하는 행동은 만들지 않는다.
5. **취약한 사람을 닮은 NPC일수록 포교가 안 되게 설계한다.** 실제 피해 보도에 나오는 집단(취준생, 신입생, 노인, 외국인 관광객)을 닮은 NPC는 속는 역할이 아니라 플레이어를 역으로 제압하는 역할을 맡긴다. 어린이 NPC는 합류하지 않는다.
6. **현재 콘텐츠 예시에 실존 종교 용어가 이미 몇 개 섞여 있다.** `길거리 전도사`(개신교 직분명), `염주 목걸이`(불교 법구), `월요병 구원회`·`만성피로 구원단`('구원파' 연상), `저 교회 다녀요`(실존 종교 언급), 엠블럼 `🐟`(기독교 상징으로 읽힐 수 있음) 등이다. 6.5절에 파일·줄 번호와 대체안을 적었다.
7. **자유 입력은 가드레일의 가장 약한 고리다.** 교단 이름과 계시를 자유 입력으로 받으면 실존 단체명이 들어온다. 단어 조합식 빌더를 기본으로 하고, `REAL_GROUPS` 차단 목록을 6.6절 수준으로 넓혀야 한다.

### 1.2 공통 원리 8가지 [추론]

1. **평범한 세계, 이상한 한 명.** 세계가 진지할수록 주인공의 헛짓이 웃기다. 배경까지 우스꽝스럽게 만들면 대비가 사라진다.
2. **정색하는 상대역.** 웃긴 건 리액션이다. NPC가 고개를 돌려 2초간 쳐다보는 것만으로 대사 없이 웃긴다.
3. **플레이어가 셋업, 게임이 펀치라인.** 플레이어는 선택했기 때문에 결과가 "내 농담"이 된다.
4. **실패가 보상이다.** 실패 연출이 성공 연출보다 다양하고 화려해야 한다. 실패에도 수집·업적·자막을 준다.
5. **반복 후 배신.** 세 번 같게, 네 번째에 다르게.
6. **작게, 짧게, 읽기 쉽게.** 개그 하나는 3~4초 안에 끝나고, 모바일 화면에서 실루엣만으로 읽혀야 한다.
7. **남이 봐야 웃긴다.** 행렬 길이, 자막, 굴욕은 주변 플레이어에게도 보여야 한다.
8. **많이 쓰고 많이 버린다.** What the Golf는 절반 이상을 버렸다. 대사 풀은 스크린샷·공유율로 걸러 낸다.

### 1.3 한 번의 포교 = 농담 한 개: 박자표 [추론]

| 단계 | 시점 | 화면에서 일어나는 일 |
|---|---|---|
| 셋업 | 0ms | 플레이어 멘트 말풍선(타자 효과 200~250ms) |
| 정적 | +400~900ms | NPC가 걸음을 멈추고 고개를 돌려 쳐다봄, "…" 말풍선, 배경음 볼륨 살짝 내림 |

### 2.1 예능 자막 시스템 (1위)

- **무엇**: 포교 결과, 연속 실패, 승급, 단속 같은 이벤트마다 화면 하단에 큰 자막을 1.2~1.8초 띄운다. 진지한 순간은 궁서체, 호들갑은 굵은 고딕, 속마음은 작은 회색 글씨.
- **근거**: [확인] 엑스포츠뉴스(2013-07-10): 무한도전 자막은 정보 전달이 아니라 제작진이 출연자에게 말을 걸듯 생각을 드러내고 상황을 세밀하게 묘사한다. 궁서체 자막과 "해골 스티커"로 스타일이 잡혔고, 상황체·강조체·코미디 자막체를 나눠 쓰며, 에피소드마다 폰트 디자인을 바꾼다. 예: 몸개그 장면에 "그간 벤치만 지켰던 묵은 한을 마음껏 토해내리라", 양치 장면에 "잇몸 건강에 힘쓰는 어르신".
- **자막 문법 3가지**: (a) 감정이입 자막(인물의 속마음을 대신 말함) (b) 과장 칭호(평범한 행동에 거창한 이름) (c) 건조한 사실 보도("거절 17회째").
- **구현**: 서버는 키와 숫자만 보낸다. 문구 선택과 렌더는 클라이언트 DOM. 대역폭과 서버 부하가 사실상 0이다.

```ts
// shared/content/captions.ts (신규 제안)
export type CaptionKey =
  | 'reject' | 'flee' | 'ignore' | 'join' | 'failStreak' | 'rankUp' | 'patrol' | 'lineLong' | 'leave' | 'offer' | 'idle'
export interface CaptionDef {
  text: string                       // '{n}' 자리에 숫자 치환
  style: 'gungseo' | 'pop' | 'whisper'
  min?: number                       // n 이 이 값 이상일 때만 후보
}
export const CAPTIONS: Record<CaptionKey, readonly CaptionDef[]> = {
  reject: [{ text: '오늘의 거절: {n}번째', style: 'pop' }, { text: '깔끔하게 거절당했다', style: 'gungseo' }],
  failStreak: [{ text: '거절 {n}연속. 이쯤 되면 재능', style: 'gungseo', min: 5 }],
  // ...4.4절 목록
}

// client: 서버 메시지 { t:'cap', k:'reject', n:17, s:seed } 수신 시
function showCaption(k: CaptionKey, n: number, seed: number) {
  const pool = CAPTIONS[k].filter((c) => (c.min ?? 0) <= n)
  const c = pool[seed % pool.length]
  el.textContent = c.text.replace('{n}', String(n))
  el.dataset.style = c.style
  el.animate([{ transform: 'scale(1.6)', opacity: 0 }, { transform: 'scale(1)', opacity: 1 }],
    { duration: 140, easing: 'cubic-bezier(.2,1.6,.4,1)' })
}
```

[data-style='gungseo'] { font-family: 'Gungsuh', 'GungSeo', 'Batang', 'AppleMyungjo', 'Noto Serif KR', serif; letter-spacing: -0.02em; }

- **주의**: 자막은 남을 놀리는 데 쓰지 않는다. 다른 플레이어에게 보이는 자막은 "당사자가 웃을 수 있는 것"만 쓴다(패배 자막도 "말로는 졌다. 표정은 이겼다." 같은 식). 기기별 글꼴 유무와 웹폰트 라이선스는 확인 못함.

### 2.2 실패가 더 웃긴 거절 + 거절 도감 + 동정 합류 (2위)

- 거절 대사를 합류 대사보다 3배 많이 쓴다. NPC 유형별 5개 이상, 범용 풀 20개 이상(4.3절).
- **거절 도감**: 처음 들은 거절 대사를 수집한다. "거절 수집률 37%"가 임명장에 찍힌다. 실패가 진행도가 된다.
- **전설의 거절**: 1% 확률의 희귀 거절(길 한복판에서 죽은 척, 불합격 통보문 낭독). 스크린샷 유도.
- **동정 합류**: 이미 `joinChance`에 연속 실패 보정(`failStreak * 0.035`)이 있다. 여기에 전용 결과를 붙인다. 7연속 실패 후 합류하면 대사가 "…그냥 불쌍해서 따라가 드릴게요."로 바뀌고 자막 "(동정표 획득)"이 뜬다. 새 통계 키 `pityJoins` 제안.
- **확률을 숨기지 않는다**: "성공률 4%"를 보여 주고 붙으면 더 크게 웃긴다. `JOIN_CHANCE_MIN = 0.04`가 이미 있다.

### 2.3 신도 콩가 행렬 (3위)

- 신도가 교주 뒤로 한 줄로 따라온다. 줄 길이가 곧 지위이고, 멀리서도 보인다.
- 유형별 걸음: 헬창은 런지로, 할머니는 뒷짐 지고, 브이로거는 뒤로 걸으며 촬영, 고양이는 줄 밖에서 따로.
- **줄이 끊기는 순간이 하이라이트**: 교주가 급정거하면 뒤에서부터 차례로 부딪혀 도미노처럼 주저앉는다. 막차 시간 이벤트에는 직장인 신도가 한꺼번에 이탈한다.
- **구현**: 서버는 "누가 누구의 몇 번째 신도인가"만 보낸다. 위치는 클라이언트가 리더의 이동 궤적에서 계산한다. 신도 20명을 매 틱 동기화할 필요가 없다.

```ts
// 리더 궤적을 일정 거리마다 저장하고, i번째 신도는 (i+1)*GAP 만큼 과거 지점을 따라간다.
const STEP = 0.15, GAP = 0.9 // m
class Trail {
  private pts: { x: number; z: number }[] = []
  push(x: number, z: number) {
    const p = this.pts[0]
    if (!p || Math.hypot(x - p.x, z - p.z) >= STEP) {
      this.pts.unshift({ x, z })
      if (this.pts.length > 700) this.pts.pop()
    }
  }
  at(i: number) { return this.pts[Math.min(this.pts.length - 1, Math.round(((i + 1) * GAP) / STEP))] }
}
// 뒤뚱거림: y 회전에 sin(t*6 + i*0.7) * 0.08 을 더하면 줄 전체가 파도처럼 흔들린다.
```

- **성능**: 방 20명 x 신도 최대 20명이면 캐릭터 400개다. InstancedMesh, 먼 신도는 머리+몸통 2개 파츠만. 한 플레이어의 표시 신도 수에 상한(예: 20명, 초과분은 줄 끝의 "+12" 팻말)을 둔다. 산사는 부하 때문에 이동 가능 면적을 74% 줄였다(02 문서).

### 2.4 정색하는 시민: 쳐다보기와 정적 (4위)

- 교주가 반경 3m에 들어오면 NPC의 머리가 교주 쪽으로 돈다(좌우 70도 제한, 초당 8 정도의 보간). 말을 걸면 걸음을 멈추고 정면으로 쳐다본다.
- 유형별 변주: 이어폰 행인은 끝까지 안 돌아본다. 고양이는 천천히 돌아보고 다시 고개를 돌린다. 대각선 회피형은 교주가 다가오면 진로를 슬쩍 비튼다([확인] 당근 동네생활 댓글의 실제 대처법: "살짝 대각선으로 간격 벌려서 갑니다").
- 머리 위 생각 풍선("?", "…", "(바쁨)")으로 상태를 읽을 수 있게 한다. Goose Game이 NPC 상태 표시를 하나씩 늘려 간 방식과 같다.

### 2.5 쫓기는 교주: 단속반, 호루라기, "평범한 척" (5위)

- **추격의 방향이 핵심이다.** 거절한 시민을 플레이어가 쫓아가는 건 현실의 괴롭힘을 닮는다(실제 피해 증언: "버스 정류장까지 쫓아왔다", "3분을 따라다녔다" [확인] 당근 댓글). 추격전은 항상 **교주가 쫓기는** 구도로 만든다.
- 단속반이 등장하면 신도들이 "저 모르는 사람이에요" 하며 흩어진다. 교주는 도망치거나, 제자리에서 "평범한 시민인 척" 동작(휘파람, 휴대폰 보는 척)을 유지해야 한다.
- 초등학생 NPC에게 말을 걸면 호루라기를 불어 단속반을 부른다. 합류 확률은 0이다.
- 같은 NPC에게 거절 직후 다시 말을 걸면 "창피 게이지"가 오르고 주변 NPC의 도망 확률이 오른다. 끈질김에 보상을 주지 않는다.

### 2.6 반복 후 배신: 멘트 피로도 (6위)

- 같은 방에서 최근 60초 안에 같은 멘트가 3번 이상 쓰이면 NPC가 말을 끊는다. "도를—" "모릅니다." / "인상이—" "네, 좋아요. 안녕히 가세요."
- 스팸 억제와 개그를 동시에 해결한다.

```ts
// PitchContext 에 lineUses(최근 60초 방 전체 사용 횟수) 추가 제안
if (ctx.lineUses >= 3 && rnd() < 0.5) return { outcome: 'no', say: pick(PREEMPT_LINES, rnd), chance }
c -= Math.min(ctx.lineUses, 5) * 0.03
```

### 2.7 뒤뚱 물리 (7위)

- 진짜 랙돌은 쓰지 않는다. 큰 머리에 스프링-댐퍼(강성 40, 감쇠 6 근처에서 튜닝)를 달아 방향 전환 때 머리가 늦게 따라오게 한다. 급정거 시 앞으로 쏠렸다 돌아온다.
- 플레이어끼리 부딪히면 둘 다 0.4초 휘청(이동 불가는 아님). 볼라드·비둘기에 걸리면 엉덩방아.
- 전부 클라이언트 연출이고 서버 판정과 무관하게 둔다.

### 2.8 쓸모없는 전용 버튼과 근접 말풍선 (8위)

- 거위의 꽥 버튼에 해당하는 전용 버튼 하나: "도를…!" 외치기. 게임상 효과는 없고 주변 NPC가 움찔할 뿐이다.
- 말풍선은 프리셋만. 반경 8m 밖에서는 글자가 작아지다 "…"만 보인다. 말하는 도중 단속반이 뜨거나 넘어지면 말풍선이 "도를 아십ㄴ—"에서 끊긴다.
- 말풍선이 떠 있는 동안 입 모양을 2프레임으로 움직인다.

### 2.9 에스컬레이션 (9위)

- 직급이 오를수록 능력이 아니라 **민망함**이 커진다. 후광은 성스러운 빛이 아니라 형광등 링, 망토는 돗자리, 왕좌는 접이식 캠핑 의자, 공중부양은 5cm.
- 최고 직급 "우주급 절대교주"는 머리가 가장 크고, 걸을 때마다 효과음이 난다. 숨을 수가 없다.
- 직급은 재미를 잠그지 않는다. 0직급도 포교, 춤, 기싸움을 다 할 수 있어야 한다(Peak 팀이 말한 "어긋나지 않는 친구 그룹").

### 2.10 조공 탑 (10위)

- 조공함 옆에 받은 물건이 실물로 쌓인다. 탑이 높아지면 흔들리고, 누가 부딪히면 와르르 무너졌다가 5초 뒤 복구된다.
- 물건 설명문이 개그의 본체다(4.7절). 세트 완성 개그: "한 짝만 남은 양말"(기존 아이템)과 전설 등급 "나머지 한 짝".
- **플레이어가 요구하는 동작은 없다.** NPC가 스스로 놓고 가고, 물건은 전부 쓸모없다.

### 2.11 계시 매드립 (11위)

- 자유 입력 대신 슬롯 선택: [시점] + [대상] + [사건] + [지침]. 조합 결과를 단상에서 궁서체로 발표한다.
- 군중 NPC가 받아 적고, 다른 플레이어는 "오오…"나 "…네?" 리액션을 누른다. 리액션 비율이 임명장에 찍힌다.

### 2.12 부조리 업적 (12위)

- 실패, 무위, 엉뚱한 행동에 업적을 준다(4.8절). 반업적 예: 5분간 가만히 서 있기, 고양이에게 20번 무시당하기.

### 2.13 기싸움과 포교 배틀 (13위)

- NPC 라이벌과의 기싸움 규칙은 이미 `DuelDef` 주석에 있다: "정답은 더 황당한 쪽". 플레이어끼리의 1:1 포교 배틀도 같은 원칙을 쓴다. 말이 되는 쪽이 아니라 더 황당한 쪽이 이긴다. 라운드는 15~20초.
- 플레이어 배틀에서는 패자의 신도 일부가 광장을 가로질러 승자 쪽으로 줄지어 이동한다. 모두에게 보이는 가벼운 굴욕이고, 30초 뒤 절반은 "아 맞다" 하며 돌아온다.

### 2.14 돌발 이벤트 (14위)

- 5~10분에 한 번 방 전체 이벤트(4.10절). 정시 이벤트(예: 매시 정각 "전체 계시 시간")는 산사의 정시 예불처럼 재방문 이유가 된다.

### 2.15 흑역사 요약 임명장 (15위)

- 직급만 찍지 말고 굴욕 통계를 찍는다: "거절당한 횟수 87회", "고양이에게 무시당함 12회", "단속반과의 전적 2승 5패", "가장 많이 들은 말: '바빠요'".
- 하단에 "본 임명장은 아무 효력이 없습니다" 고지를 디자인 요소로 넣는다. 관공서·실제 종교 단체 문서처럼 보이는 문양·직인은 쓰지 않는다.

## 3. "도를 아십니까" 밈 문화

### 3.1 실제로 쓰이는 접근 방식 (재현 금지 범위를 정하기 위한 조사)

[확인] 더팩트 탐사보도(2021-06-05)에 기록된 흐름:

1. 2인 1조가 행인에게 칭찬으로 말을 건다. 기사 속 표현: "기운이 천복이 있어요", "인상이 좋아서 말씀드리는 거예요".
2. 신상을 묻는다("집안에서 맏이에요?", "무슨 일 하고 계세요?").
3. 자리를 옮기자고 한다("카페에서 차라도 마시면서").
4. 조상과 막힌 기운을 말하며 제사를 권한다.
5. 비용을 요구한다(기사 속 표현: "한 살당 만 원", "오늘이 날이기 때문에").
6. 합숙 장소로 데려가 의식을 치르고, 다음 방문을 약속받는다.

[확인] Creatrip 글: "도를 아십니까"는 1990년대 중후반에 널리 쓰여 전국적으로 유명해졌고, 지금은 이 문장 자체를 쓰는 경우는 드물다. 문장이 워낙 유명해서 길거리 포교자를 통칭 "도믿맨"이라 부른다. 다른 접근법으로 길 묻기, 설문지, 심리 테스트, 인상·기운 언급, 가짜 길거리 캐스팅, 호감 있는 척, 작가·웹툰 취재 사칭, 관광객에게 "한국 문화 체험"이라며 의식에 참여시키고 돈을 요구하는 방식을 든다.

[확인] 더팩트(2026-03-07): 새 학기 대학가에서 동아리·해외 봉사를 내세운 부스, 다트 게임과 간식, 설문으로 이름·학과·전화번호 수집, 입학식 뒤 혼자 있는 신입생을 카페로 데려가는 사례가 보도됐다. [요약] MBTI, 도형 상담, 진로 멘토링을 내세운 접근도 여러 매체에 보도됐다.

**설계 결론 [추론]**

- 1번 단계의 굳은 문장("도를 아십니까", "인상이 좋으세요", "기운이 맑으시네요")만 밈으로 빌린다.
- 2~6번 단계는 게임 행동으로 만들지 않는다: 신상 묻기, 자리 옮기기 제안, 제사·의식, 돈 요구, 합숙, 재방문 약속.
- 설문, 심리 테스트, MBTI, 동아리 사칭, 취재 사칭은 현재 진행형 수법이다. 플레이어 멘트로 쓰지 않는다. NPC가 경계하는 대사("어, 설문조사인가요?")로만 등장시킨다.
- 한복 + 병풍 + 제사상 + 종이 태우기는 기사에 묘사된 실제 의식 장면이다. 비밀 본부 연출에 쓰지 않는다.

### 4.9 기싸움 6개 (`DuelDef`, 더 황당한 쪽이 이긴다)

4. 라이벌: "저는 사흘 동안 잠을 안 잤습니다." → 정답: "저는 사흘 동안 잠만 잤습니다." / 승리: "그건… 수행이 아니라 주말 아닙니까? 부럽습니다."

### 4.10 돌발 이벤트 10개

1. **할머니 순방**: 요구르트 할머니가 광장을 가로지른다. 반경 안의 모든 교주가 3초간 붙잡혀 간식을 받는다. 전원 조공 1개.
2. **비둘기 대이동**: 누군가 과자를 흘린다. 비둘기 떼가 가장 긴 행렬을 덮치고 신도가 흩어졌다 10초 뒤 돌아온다.
3. **소나기**: 시민 전원이 편의점 처마 밑으로 모인다. 포교 명당이 되지만 다들 등을 돌리고 있다. 우산 조공 확률 상승.
4. **단속반 순찰**: 모든 교주가 동시에 "평범한 척"을 해야 한다. 한 명이라도 춤을 추고 있으면 그 사람만 쫓긴다.
5. **막차 시간**: 직장인 전원이 지하철 입구로 질주한다. 직장인 신도가 통째로 빠져나가 행렬 중간이 끊긴다.
6. **미확인 비행 물체 통과**: 하늘에 뭔가 지나간다. 최고 직급 교주만 "교신" 동작으로 반응할 수 있는데 답장은 오지 않는다. 신도들은 넋 놓고 하늘을 보다가 줄에서 뒤처진다. (신도가 끌려가거나 따라 떠나는 연출은 쓰지 않는다. 6.1절 참조.)
7. **단상 점거**: 고양이가 단상에서 잠든다. 깰 때까지 아무도 계시를 발표할 수 없다. 서열은 고양이, 교주 순이다.
8. **가로등 정전**: 후광 장식이 있는 교주만 빛난다. 시민들이 "오, 밝다" 하며 모여든다. 믿어서가 아니라 유용해서.
9. **라이벌 대집회**: NPC 교주가 광장에서 계시를 발표한다. 플레이어들이 야유 말풍선으로 맞불을 놓으면 라이벌이 삐져서 떠난다.
10. **전설의 행인**: 1% 확률로 모든 멘트에 "오, 좋네요" 하는 시민이 나타난다. 끝까지 따라온 뒤 묻는다. "근데 제가 뭘 믿기로 한 거죠?"

- **표적을 "행동"에 둔다**: [확인] Monty Python의 Life of Brian(1979)에 대해 John Cleese는 영화가 놀린 것이 그리스도가 아니라 "기독교인인 척하는 사람들의 방식"이라고 설명했다. Terry Gilliam은 팀이 표적을 가려 골랐다고 말했다. 그래도 투자사가 촬영 전에 자금을 뺐고, 미국 여러 지역과 아일랜드·노르웨이에서 상영이 금지됐다(Literary Hub). → 방어 논리가 분명해도 반발은 온다. 실존 신앙과 닿는 면적 자체를 0에 가깝게 줄이는 편이 낫다.
- **안전한 표적을 고른다**: [확인] What the Golf? 팀은 골프를 고른 이유를 "주로 부자들이 치는 운동이라 안전한 표적"이라고 했다(위키백과). → 우리 표적은 "끈질긴 권유"와 "교주의 허세"다. 믿는 사람이 아니다.
- **상대역을 아낀다**: [확인] House House는 놀림당하는 주민을 "하루를 보내려는 노동 계급 사람들"로 보고 깊은 애정을 갖고 만들었다(VICE). → 시민 NPC를 바보로 그리지 않는다.
- **귀여움은 완충재일 뿐 면죄부가 아니다**: [확인] Cult of the Lamb 팀은 귀여운 아트 덕에 끔찍한 것을 넣을 수 있었다고 했다(Game Developer). 우리는 그 여유를 수위를 올리는 데 쓰지 않고, 수위를 낮게 유지한 채 더 안전하게 만드는 데 쓴다.
- **"무엇을 위한 풍자인가"가 안 보이면 조롱으로 읽힌다**: [요약] 2024년 SNL 코리아 논란(3.3절).

### Do

- [ ] 웃음거리는 교주(플레이어)와 그의 허세·끈질김이다. 모든 개그에 "누가 우스워지는가"를 물어 플레이어 쪽인지 확인한다.
- [ ] 시민 NPC는 평범하고 정색하며, 언제든 떠날 수 있다. 이탈("정신을 차렸습니다")은 실패가 아니라 개그다.
- [ ] 굳은 포교 문장은 같은 문장 안에서 생활 소재로 꺾는다.
- [ ] 교단 소재는 음식, 직장 생활, 잠, 날씨처럼 누구의 신앙과도 겹치지 않는 것으로 한다.
- [ ] 취약 집단을 닮은 NPC(노인, 취준생, 관광객, 신입생)는 속지 않고 플레이어를 제압한다. 어린이는 합류하지 않는다.
- [ ] 조공은 NPC가 스스로 놓고 가는 쓸모없는 잡동사니다. 가상 코인은 현금·결제와 연결하지 않는다.
- [ ] 이름, 계시, 말풍선은 프리셋·조합식을 기본으로 한다.
- [ ] 타이틀, 로딩 팁, 임명장에 "전부 허구, 실존 단체와 무관" 고지를 넣는다. 고지문 자체를 개그 톤으로 써서 읽히게 한다.
- [ ] 현실 대처 안내를 한 줄 넣는다: "현실에서 불쾌한 권유를 받으면 대꾸하지 않고 지나가도 됩니다. 계속 따라오면 112."
- [ ] 새 콘텐츠는 6장의 차단 목록으로 자동 검사하고, 사람 한 명이 "실존 단체가 떠오르는가"를 본다.

### Don't

- [ ] 실존 종교, 교단, 신종교, 정치 단체, 인물의 이름·교리·용어·상징·복식을 쓰거나 닮게 하지 않는다.
- [ ] 믿음 자체, 신자, 피해자를 놀리지 않는다. "속는 사람이 바보"라는 구도를 만들지 않는다.
- [ ] 실제 수법의 다음 단계를 행동으로 만들지 않는다: 신상 묻기, 연락처 받기, 자리 옮기기, 제사·의식, 돈 요구, 합숙, 가족과 떼어 놓기.
- [ ] 불안을 건드리는 멘트를 쓰지 않는다("액이 꼈다", "막혀 있다", "큰일 난다"). 실제 설득·조종 기법을 설명하거나 보상하지 않는다. 멘트 상성은 "취향 개그"일 뿐 심리 기법처럼 보이면 안 된다.
- [ ] 거절한 NPC를 쫓아가거나 반복해서 말 거는 행동에 보상을 주지 않는다.
- [ ] 감금, 세뇌, 착취, 폭력, 집단 사망, "다 같이 떠나자" 계열 농담을 쓰지 않는다. 실제 사건을 떠올리게 한다.
- [ ] 경전 문체와 기적 서사를 패러디하지 않는다("~하는 자는 복이 있나니", 물 위 걷기 등).
- [ ] 국적, 성별, 나이, 장애, 지역, 외모, 억양을 웃음 소재로 쓰지 않는다. 유형 개그는 "생활 습관"에서 뽑는다.
- [ ] 실제 돈, 실제 후원, 유료 뽑기를 조공함과 엮지 않는다.
- [ ] 임명장을 관공서 문서나 실제 단체의 임명장처럼 보이게 만들지 않는다.

### 출시 전 60초 점검 질문

1. 이 대사를 실제 길거리에서 그대로 쓰면 포교가 되는가? 된다면 버린다.
2. 이 장면을 피해자 가족이 보면 자기 일이 떠오르는가? 그렇다면 버린다.
3. 이 이름을 검색하면 실존 단체가 나오는가? 나오면 바꾼다.
4. 웃음거리가 교주가 아니라 시민인가? 그렇다면 뒤집는다.

## 6. 닮으면 안 되는 이름, 단어, 상징

이 목록은 "나쁜 단체 목록"이 아니다. 평가와 무관하게 **실존하는 종교·단체·인물은 전부** 피한다는 차단 목록이다. 2023년에 잘못된 "특정 단체 동아리 명단"이 퍼져 무관한 단체가 피해를 본 일이 있었다([요약] 서울신문 2023-03-23). 이름이 우연히 겹치는 것만으로도 누군가 다친다.

### 6.1 실존 종교·교단·단체명

- **주요 종교와 교파** [상식]: 기독교, 개신교, 천주교(가톨릭), 정교회, 성공회, 불교, 원불교, 천도교, 유교, 도교, 이슬람, 힌두교, 유대교, 대종교, 증산도, 무속(무당, 굿). 교파명: 장로교, 감리교, 침례교, 성결교, 순복음, 구세군, 조계종, 천태종, 태고종 등.
- **이번 조사에서 원문·검색 결과에 실명으로 등장한 단체**: 대순진리회, 신천지([확인] Creatrip 글이 길거리 포교 단체의 예로 듦. 신천지는 더팩트 2026 기사의 학생 발언에도 등장), JMS(기독교복음선교회), 아가동산([요약] 다큐멘터리 방송금지 가처분 보도), 구원파·기독교복음침례회·기쁜소식선교회([확인] 한국어 위키백과 '구원파'), 영생교, 다미선교회, 여호와의 증인, 오대양([요약] 1999년 서울신문), 더 포 윈즈 캠퍼스([확인] 더팩트 2026 기사에 부스명으로 등장).
- **그 밖에 피할 이름** [상식, 검수 필요]: 통일교(세계평화통일가정연합), 하나님의교회, 만민중앙교회, 천부교(전도관), 은혜로교회, 파룬궁, 사이언톨로지, 옴진리교, 인민사원, 헤븐스 게이트, 라엘리안 무브먼트.
- **우주 소재 주의** [상식]: UFO·외계 교신을 교리로 삼는 실존 단체가 있다. 우리 `cosmic` 카테고리와 "우주급 절대교주"는 "안드로메다 부재중 전화" 수준의 생활 개그로만 쓰고, 외계 창조주, 우주선 탑승·승천, 육신을 떠남 같은 서사는 쓰지 않는다.
- **패러디 종교** [확인]: 날아다니는 스파게티 괴물교(파스타파리안)는 2005년에 만들어진 패러디 종교이고, 미트볼 두 개가 달린 면발 뭉치로 그려진다(한국어 위키백과). "라면교"는 면 요리 소재가 겹친다. 미트볼 달린 면발 괴물 이미지는 피한다. 이 종교의 맺음말로 알려진 "라멘"도 피한다([상식]).

## 7. 우리 게임에 적용할 것

우선순위 순이다.

1. **표적 규칙을 콘텐츠 가이드 첫 줄에 적는다**: "웃음거리는 항상 교주다. 시민은 평범하고, 정색하고, 언제든 떠난다." 모든 대사 리뷰의 기준으로 쓴다.
2. **6.5절 충돌 후보를 정리한다.** 직급명 `길거리 전도사`, `염주 목걸이`, `구원회`·`구원단`, `교회 다녀요`, `헌금함` 표기부터. 문구만 바꾸면 되고 id는 유지된다.
3. **`REAL_GROUPS`를 6.6절로 확장하고 교단 이름 조합 빌더를 기본 UI로 만든다.**
4. **예능 자막 시스템을 1순위 메커닉으로 구현한다**(2.1절 스니펫). 서버 메시지는 키 + 숫자 + 시드 3개 필드면 된다.
5. **포교 박자표(1.3절)를 대화 UI에 적용한다.** 정적 구간과 NPC 쳐다보기만 넣어도 같은 대사가 훨씬 웃긴다.
6. **거절 대사를 합류 대사의 3배로 쓰고 거절 도감을 만든다.** 4.1~4.3절 대사를 `archetypes.ts`에 옮기고, 3배수로 써서 플레이 테스트 후 3분의 1만 남긴다.
7. **취약 집단 NPC 규칙을 스키마 수준에서 강제한다.** 예: `Archetype`에 `recruitable: false` 필드를 두고 `kid`, `tourist`는 `joinChance`가 0을 반환하게 한다. 현재 `JOIN_CHANCE_MIN = 0.04`가 하한이라 그대로는 어린이도 4% 확률로 합류한다.
8. **행렬은 클라이언트 궤적 추종으로 구현한다**(2.3절). 서버는 순번만 보낸다. 표시 신도 수 상한을 둔다.
9. **추격은 교주가 쫓기는 구도로만 만든다.** 거절 직후 재시도에는 창피 게이지 페널티.
10. **멘트 피로도**를 `PitchContext.lineUses`로 넣는다(2.6절).
11. **계시는 매드립 슬롯으로 받는다.** 자유 입력을 없애면 모더레이션과 가드레일이 한 번에 해결된다.
12. **조공함은 "요구 버튼 없음, 전부 잡동사니, 코인은 현금과 무관"을 UI에서 드러낸다.** 명칭은 조공함.
13. **임명장에 굴욕 통계와 "아무 효력 없음" 고지를 넣는다.**
14. **실제 수법 6단계(3.1절)를 금지 행동 목록으로 테스트에 넣는다.** 예: 콘텐츠 문자열에 "연락처", "전화번호", "카페 가서", "제사", "절값"이 들어가면 실패하는 단위 테스트.
15. **현실 대처 한 줄을 로딩 팁에 넣는다**(4.11절 5번). 풍자의 방향을 플레이어에게 분명히 해 준다.

## 8. 확인하지 못한 것

- 숏박스, 피식대학, SNL코리아가 "도를 아십니까"를 직접 패러디한 영상의 존재와 내용.
- "저 교회 다녀요", "제가 도인데요" 밈의 원 출처. 다모앙 대처법 글은 403으로 원문을 열지 못했다.
- 나무위키 "도를 아십니까" 문서(차단으로 열람 실패). 한국어 위키백과에는 해당 문서가 없다.
- "도를 아십니까"와 특정 교단의 연관이 사실인지 여부. Creatrip 글이 두 단체를 예로 들 뿐이고, 위키백과 해당 교단 문서에는 언급이 없다.
- 게임물관리위원회 등급분류 규정에 종교 관련 조항이 있는지. 명예훼손·모욕 등 법적 위험의 구체적 범위(법률 자문 필요).
- Massive Monster가 실존 종교를 의도적으로 피했다는 직접 발언.
- Among Us 본편의 이모트 기능.
- 6.1절과 6.2절에서 [상식]으로 표시한 단체명과 용어의 정확성과 최신성. 출시 전에 사람이 검수해야 한다.
- 궁서체 계열 시스템 글꼴의 기기별 탑재 여부와 웹폰트 라이선스.
- Peak 판매량은 출처마다 다르다(위키백과 "1,000만 장 이상", AppMagic 추정 1,540만 장).
