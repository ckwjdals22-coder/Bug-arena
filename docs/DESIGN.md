# 게임 디자인 문서 — 도를 아십니까? 교주 시뮬레이터

> 구현자가 따라야 하는 "무엇을 만들 것인가"의 기준 문서. 숫자는 `shared/constants.ts`, 카탈로그는 `shared/content/core.ts`가 원본이다(문서와 다르면 코드가 우선).

## 0. 한 줄 요약과 원칙

귀엽고 수상한 큰 머리 캐릭터가 되어 한국의 평범한 거리에서 시민 NPC에게 황당한 포교 멘트를 던지고, 신도를 줄줄이 달고 다니며 교주로 성장하는 **실시간 멀티플레이 풍자 코미디**.

- **모든 교단·인물·교리는 허구.** 실존 종교·정치 단체·인물을 닮게 만들지 않는다(이름 필터 포함).
- **행동을 풍자한다, 신앙을 조롱하지 않는다.** 웃음의 대상은 "끈질긴 길거리 포교"라는 행동과 플레이어 자신(교주)의 허세다.
- **현실 설득 기술을 가르치지 않는다.** 성패는 확률 + NPC의 가상 성격(개그 상성)으로만 정해진다.
- **실제 돈·개인정보 없음.** 헌금함·코인은 전부 가상. 회원가입 없음.
- **톤:** 밝고 유머러스. 무섭거나 사실적인 종교시설 묘사는 하지 않는다. "어딘가 수상함"은 네온·보라색 안개·눈 모양 간판 같은 귀여운 소품으로만.
- **가짜 멀티플레이 금지.** NPC는 항상 NPC로 표시하고, 실제 접속자 수와 NPC 수를 따로 보여 준다.

## 1. 월드 — "수상역 4번 출구 앞"

좌표계: X 동(+)/서(−), Z 남(+)/북(−), Y 위. 단위 m. 걸을 수 있는 범위는 대략 **X −48..48, Z −36..36** (조정 가능, `shared/world/data.ts`가 원본).

배치 계획(월드 담당이 세부를 확정):

| 구역 | 대략 위치 | 내용 |
|---|---|---|
| 큰길 | Z −5..5, 동서로 관통 | 4차선 도로. **차는 다니지 않는다**("차 없는 거리" 현수막, 주차된 승합차/붕어빵 트럭 정도). 중앙 X −4..4 에 넓은 **횡단보도**, 신호등(보행 신호는 장식) |
| 북쪽 인도 | Z −9..−5 | 가로수, 가로등, 버스 정류장, **지하철 출입구(수상역 4번 출구)** — 서쪽 X≈−20 |
| 광장 | 중심 (0, −21), 반지름 ≈11 | 바닥 무늬, 벤치, 비둘기 느낌의 소품, 중앙에 **원형 단상**(반지름 2.6, 높이 0.5, 경사로) |
| 포교 부스 거리 | 광장 동쪽 X 14..26, Z −16..−12 | 파라솔/접이식 테이블 **포교 부스** 3개("기운 무료 측정", "관상 봐 드립니다" 같은 허구 간판) |
| 북쪽 배경 | Z < −33 | 아파트/오피스 건물 벽(경계) |
| 남쪽 인도 | Z 5..9 | 가게 앞 |
| 상가 | Z 9..20 | 편의점, 분식 포장마차, 노래방/PC방 건물 등 한국 거리 간판(전부 허구 상호) |
| 수상한 천막 | (10, 16) 부근 | 줄무늬 천막 + **가상 헌금함** |
| 골목 → 비밀 교단 건물 | X −3..3, Z 20..33 | 골목 끝에 보라색 네온 눈 간판의 **비밀 교단 건물**. 직급 3(신흥 교단장)부터 문이 열린다. 안에는 방석과 왕좌 |
| 길 끝 | X ±46 | NPC가 드나드는 출구(버스 정류장 방향) |

- 지면은 평평(y=0)하고 단상만 솟아 있다(`groundHeight`).
- 충돌체는 축 정렬 박스 + 원. 플레이어·NPC 모두 반지름 ≈0.45 원으로 취급.
- NPC는 `nav`(노드+간선) 위를 걷는다. 노드 종류: walk/plaza/cross/shop/rest/exit.
- 분위기: 해 질 녘 직전의 따뜻한 하늘(하늘색→복숭아색 그라데이션), 옅은 보라빛 안개, 평면 음영 로우폴리, 가짜 그림자(발밑 원형).

## 2. 캐릭터

- **비율:** 머리가 크고 몸이 작다(전체 키 ≈1.5m, 머리 지름 ≈0.75m). 팔다리는 짧은 캡슐/박스. 눈은 점 두 개, 입은 작은 선 — 표정은 눈/입 모양 바꾸기로 표현.
- **외형(Look):** `[피부, 복장, 색, 모자, 얼굴, 소품, 오라]` — 카탈로그는 `shared/content/core.ts`.
  - 처음부터: 평범한 시민 / 후드티 / **수상한 전도사**(흰 셔츠+검은 넥타이) / **초보 교주 도복**.
  - 직급이 오르면 갓·삿갓·은박지 모자·황금 로브·후광·우주 오라 등이 열린다.
- **상태 애니메이션(Anim):** Idle(숨쉬기 흔들림) / Walk / Run / Sprint(양팔을 뒤로 뻗고 허둥지둥) / Listen(NPC가 고개를 갸웃) / Cheer(양팔 번쩍 폴짝) / Stun(얼어붙어 부들부들, 머리 위 별) / Vanish(작아지며 사라짐).
- **이모트:** (모두 다른 플레이어에게 실시간 표시)
  - wave 손 흔들기 · bow 허리 숙여 인사 · smirk 수상한 미소(눈이 초승달, 몸을 살짝 기울이고 손 비비기) · pray 두 손 모으기 · flyer 전단지 흔들기(손에 종이) · preach 양손 번쩍 설교 · dance 신비로운 춤(팔을 물결처럼, 제자리 회전) · flee 도망가기(스프린트 발동)
  - 해금: cheer 만세 · kneel 큰절 · spin 회전 수련 · point 계시의 손가락 · levitate 공중부양(가부좌로 둥실) · cosmic 우주 교신(머리 위 안테나 전파)
  - 반복 이모트는 이동하면 풀린다.

## 3. 조작과 카메라

- **PC:** WASD/방향키 이동, Shift 달리기, 마우스 드래그로 카메라 회전, 휠 줌, 숫자 1~8 이모트, E/Space 상황 버튼(말 걸기 등), 지면 클릭 이동, Esc 닫기.
- **모바일:** 왼쪽 가상 조이스틱(끝까지 밀면 달리기), 오른쪽 큰 상황 버튼 + 이모트/도망 버튼, 빈 화면 드래그로 카메라 회전, 두 손가락 핀치 줌, 지면 탭 이동.
- **카메라:** 3인칭 추적. 기본 거리 ≈11m, 내려다보는 각도 ≈38°. 줌 6~18m. 플레이어를 부드럽게 따라간다. 회전은 선택 사항(안 돌려도 플레이 가능).
- 이동은 카메라 방향 기준. 캐릭터는 이동 방향으로 부드럽게 회전.
- **입장까지:** 첫 화면에는 임의 닉네임이 이미 채워져 있고 **[바로 입장]** 한 번이면 게임 시작. 방 선택·닉네임 수정은 같은 화면에서 선택 사항.

## 4. 핵심 루프: 길거리 포교

1. 시민 NPC 근처(2.8m)에 가면 **[말 걸기]** 상황 버튼이 뜬다(NPC 발밑 강조).
2. 누르면 서버가 대화 세션을 연다. NPC는 멈춰 서서 플레이어를 본다. NPC 첫마디 + **멘트 4개**(해금된 것 중 소재가 겹치지 않게) 제시.
3. 멘트를 고르면 서버가 판정:
   - **join** 합류 → "신도 +1", NPC가 플레이어를 졸졸 따라다님(최대 6명, 약 100초 뒤 "정신 차리고" 떠남. 누적 신도 수는 줄지 않는다)
   - **more** "흥미로운데요? 더 들어볼게요." → 멘트를 한 번 더 고른다(성공 확률 크게 상승)
   - **no** 말로 거절하고 제 갈 길
   - **flee** 비명과 함께 전력 질주(먼지 이펙트) — "1분만요" 같은 멘트는 도망 확률이 높다
   - **ignore** 못 들은 척
   - **rival** "저도 사실 교주입니다" → 기싸움(2단계)
   - **king** "혹시 전생에 제가 왕이었나요?" → 감격하며 합류 + '전생의 왕' 카운트
4. 결과는 방 전체에 방송된다(플레이어 말풍선 = 고른 멘트, NPC 말풍선 = 반응).
5. 쿨타임: 포교 후 2.2초. 거절한 NPC는 35초간 같은 사람 말을 안 듣는다.

**확률:** `합류 확률 = NPC 기본값 + 소재 취향 + 멘트 보정 + 직급×2% + 연속성공 보정 + 연속실패 동정표(회당 3.5%) + 버프`, 4%~92%로 제한. 소재(dao/face/past/ancestor/energy/time/fate/cosmic)는 개그 분류일 뿐이다.

**보상:** 합류 +10 영향력(+연속 성공 보너스 최대 +10), '더 들어볼게요' +2, 실패 +1(근성 점수).

**신도 NPC:** 주인을 따라 줄지어 걷는다(콩가 라인). 가끔 혼잣말. 시간이 다 되면 "어? 제가 왜 여기 있죠?" 하고 떠난다 → 출구로 걸어가 사라지고, 새 시민이 지하철에서 올라온다(방의 NPC 수는 일정).
다른 플레이어의 신도에게도 말을 걸 수 있다(확률 −20%, 성공 시 '신도 빼앗기').

## 6. 실제 이용자 간 상호작용

- 다른 접속자는 **이름표(닉네임 + 직급, 교단 엠블럼·이름·칭호)** 가 항상 보인다. NPC 이름표는 가까이 갔을 때만, 회색 'NPC' 표시와 함께.
- 가까운 접속자에게: 손 흔들기, 인사, **교단 가입 제안**, **포교 배틀 신청**, 차단, 신고.
- 자유 채팅은 없다. 미리 정해진 **말풍선(퀵챗)** 과 동작으로 소통한다.
- **신고**: 닉네임 신고 2명 → 중립 이름(행인NNNN)으로 바뀌고 10분 동안 이름 고정, 도배·방해 신고 3명 → 5분 동안 말풍선·초대·배틀 신청 쉬기. 자동 조치에는 **그 방에 2분 이상 머물렀고 영향력 30 이상인 사람**의 신고만 센다(막 만든 계정 여러 개로 남을 제재하지 못하게). 자격이 안 되는 신고도 운영 로그에는 남는다.
- 쿨타임·차단·입막음·이름 고정은 **재접속하거나 방을 옮겨도 유지**된다(서버가 접속자별로 잠깐 기억한다). 닉네임은 5초에 한 번만 바꿀 수 있다.

## 7. 2단계 기능 명세

### 7.1 나만의 교단
- 누구나(직급 0부터) 교단을 만들 수 있다: 이름(2~12자), 대표 색(12색), 엠블럼(이모지 24종), 교주 칭호(~8자). 추천 이름 버튼.
- 이름/칭호는 욕설·실존 단체명 필터를 통과해야 한다.
- 교단 기록: 교단이 모은 NPC 신도 수, 누적 영향력(교주와 교단원이 번 것의 합). 방 안 **교단 순위표**.
- 탈퇴는 언제든 자유(교주가 탈퇴하면 교단 해산은 아니고 교주 자리만 비는 대신, 단순화를 위해 "교주 탈퇴 = 내 교단 정보 삭제"로 처리. 이미 가입한 교단원의 표시는 그대로 남는다).

### 7.2 교단 가입 제안
- 교단이 있는 플레이어가 4m 안의 다른 플레이어에게 제안 → 상대 화면에 **초대 카드**(교단 엠블럼/이름/교주, [수락] [거절] [이 사람 차단]) 20초.
- 수락해야만 가입. 거절하면 같은 대상에게 60초 쿨타임. 전체 5초 쿨타임.
- 수락되면 초대한 사람은 영향력 +15. 단, **같은 두 사람 사이에서는 하루에 한 번만**, 그리고 **10분에 5번까지만** 준다(가입 → 탈퇴 → 재가입이나 도우미 계정으로 보상을 찍어내지 못하게). 가입 자체는 언제나 성립한다.
- 포교 링크(`?by=닉네임`)로 들어온 사람에게는 그 사람의 초대 카드가 자동으로 한 번 뜬다(초대자당 하루 한 번, 방 전체 소식은 초대자당 1분에 한 번).
- 차단하면 그 사람의 초대/배틀 신청이 더 이상 오지 않는다(보낸 사람에게는 '거절'로만 보인다). 설정에서 "초대 받지 않기"도 가능.

### 7.3 단상: 오늘의 계시
- 단상 위에서 **[오늘의 계시]** (개인 쿨타임 20초) → 무작위 황당 예언이 큰 말풍선으로 뜨고, 주변 NPC/캐릭터 위에 반응 말풍선("오오…!", "…네?"), 빛기둥 이펙트. 영향력 +5.

### 7.4 집단 설교
- 단상 위에서 **[집단 설교 시작]** (방 전체 쿨타임 75초) → 26초 이벤트.
- 광장 주변 NPC가 구경하러 모인다. 다른 플레이어는 **[설교 참여]** 로 합류.
- 3번의 구호 라운드: 화면에 구호("퇴근을 믿습니까?")가 뜨면 참여자가 제한 시간 안에 **[믿습니다!]** 버튼을 누른다. 응답한 사람 수 × 라운드로 "신앙 게이지"가 찬다.
- 종료 시 게이지에 따라 구경하던 NPC 0~5명이 교주에게 단체 합류. 교주 +25, 참여자 +12 영향력. 전원 환호 애니메이션.

### 7.5 포교 배틀
- 4m 안의 플레이어에게 신청 → 상대가 수락하면 60초 배틀. 그동안 각자 NPC 합류 수를 센다(화면 상단 점수판, 방 전체에 시작/결과 소식).
- 승자 +30, 패자 +8 영향력. 무승부 가능.
- 한 명이 나가면: 남은 사람이 **앞서고 있었을 때만** 승리로 인정한다. 동점이거나 뒤지고 있었다면 무효(보상·전적 없음) — "수락하고 바로 나가 주기"로 승리를 찍어내지 못하게.

### 7.6 가상 헌금함
- 포교 성공 시 낮은 확률로 신도가 즉석에서 물건을 내민다.
- 신도를 데리고 천막의 헌금함 앞에서 **[헌납 타임]** (쿨타임 12초) → 아직 헌납하지 않은 신도마다 터무니없는 물건 1개 + 가상 코인. 희귀도 4단계. **헌납품 도감**에 기록.
- 실제 결제·금전 요청은 어디에도 없다. 화면에도 "가상"임을 명시.

### 7.7 업적 / 일일 수행 / 도감
- 업적: 통계 카운터(`STAT`) 기준. 달성 시 알림 + 영향력 보너스. 예: 10연속 실패, 거절 100회, 전생의 왕 3명, 신도 50명.
- 일일 수행: 하루 3개(서버 날짜 KST 기준), 완료 시 보상 수령. 연속 출석 일수.
- 시민 도감: 만난 NPC 유형 기록.

### 7.8 돌발 이벤트
- **단속반:** 호루라기를 문 "구청 단속반" NPC가 순찰한다. 근처(12m)에서 포교하다 들키면 "거기! 무단 포교 금지!" 하고 쫓아온다. 잡히면 3초 얼어붙고 따라다니던 신도가 흩어진다. **도망가기(스프린트)** 로 따돌리면 '탈출' 카운트. 너무 가혹하지 않게: 추격은 최대 9초, 잡혀도 누적 신도 수는 줄지 않는다.
- **라이벌 교주:** 포교하려던 NPC가 "저도 사실 교주입니다"라며 역포교 → 3지선다 기싸움(더 황당한 답이 정답). 이기면 +신도 2, 지면 따라다니던 신도 1명을 빼앗긴다.
- **고양이:** 길고양이에게도 말을 걸 수 있다. 거의 항상 "야옹". 아주 낮은 확률로 합류(전설 업적).

### 7.9 교주 임명장
- 닉네임, 교단(엠블럼/이름/색), 직급, 신도 수, 캐릭터 초상, 날짜, 도장으로 구성한 **세로 1080×1920 PNG**를 캔버스로 생성.
- [이미지 저장] + 모바일에서는 Web Share API로 공유 시트(인스타그램 스토리 등). "모든 교단은 허구" 문구 포함.
