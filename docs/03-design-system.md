## 1. 브랜드 아이디어와 원칙

### 1.1 한 문장

**남는자리는 할인 가게가 아니라, 지금 비어 있는 자리의 시간표입니다.** 화면은 역의 출발 안내판처럼 읽힙니다. 시작 시각이 행을 이끌고, 남은 자리는 라임색 플랩 칸에 글자로 적히고, 빨강은 예약 마감에만 켜집니다.

브랜드 표식은 "자리 네 칸 중 하나가 켜져 있다"입니다. 심볼, 워드마크의 ㅁ, 행의 자리 타일, 상세의 좌석도, 사업자 보드, 사진이 없을 때의 커버가 모두 같은 타일입니다. 그래서 "한 자리 남았다"는 사실이 어디서나 같은 모양으로 그려집니다.

### 1.2 원칙 다섯 가지

| # | 원칙 | 뜻 | 화면에서 지키는 법 |
| --- | --- | --- | --- |
| 1 | **시각이 먼저** | 고객이 가장 먼저 묻는 건 "언제"입니다 | 모든 자리 행은 68px 시각 열로 시작합니다. 읽는 순서는 언제 → 무엇 → 남은 자리 → 금액 → 어디 → 왜 나왔나 |
| 2 | **잉크는 살아 있는 데이터, 종이는 조작과 읽기** | 표면 두 개에 역할을 하나씩 | 실시간으로 바뀌는 목록·알림·결제 바는 잉크, 필터·폼·설명·표·차트는 종이. 2.2절 표를 따릅니다 |
| 3 | **신호는 둘뿐** | 색이 많으면 아무것도 신호가 아닙니다 | 라임 = 열린 자리·실시간 + 자리를 움직이는 단 하나의 동작. 빨강 = 마감(종이 위에서는 오류). 그 밖의 색은 상태 뱃지와 차트에만 |
| 4 | **있는 그대로의 긴박함** | 가짜 품절·가짜 타이머는 한 번 들키면 끝입니다 | 실제 남은 수와 실제 마감 시각만 보여줍니다. 60분 안쪽일 때만 빨강. 초 단위 깜빡임 없음. 정가는 "정가"라고 씁니다 |
| 5 | **매일 쓰는 도구의 절제** | 사업자는 손님 사이에 한 손으로 봅니다 | 그림자·그라데이션·장식 없음. 선 1px, 모서리 3/6/10. 플랩 타일은 화면에 한 번, 회차 시각에만 |

### 1.3 일부러 하지 않는 것

- 보라·남색 그라데이션, 글래스모피즘, 그림자, 이모지 아이콘, 스톡 사진, 일러스트 캐릭터
- "히어로 + 카드 3장" 식 랜딩 구성. 첫 화면부터 실제 자리 목록입니다
- 라임을 글자색·선택 표시·배지 색으로 쓰는 것, 종이 위에 테두리 없이 라임을 놓는 것
- "마감 임박!", "단 1자리!", "12명이 보고 있어요" 같은 압박 문구와 초 단위 카운트다운
- 할인율 배지·취소선 가격을 기본값처럼 쓰는 것. 원래 가격을 지우는 표시는 호스트가 실제로 가격을 내렸을 때만
- 보드 행 안의 사진·썸네일. 사진은 종이 위에서만 씁니다

### 2.2 표면 규칙

어떤 것이 어느 표면에 놓이는지는 고르는 문제가 아니라 정해져 있습니다.

| 잉크(ink) 위 | 종이(paper) 위 |
| --- | --- |
| 선택한 날짜의 자리 보드(고객 홈), 사업자 '오늘 일정' 보드 | 헤더, 검색, 필터, 칩, 탭, 탭 바 |
| 상세 커버(시각 + 좌석도), 예약 패스 윗부분 | 상세의 읽는 영역(자리 선택, 금액, 환불, 호스트, 후기) |
| 하단 고정 결제 바 | 폼, 설정, 시트, 다이얼로그 |
| 지금 일어난 일 알림(기다리던 자리, 방금 취소된 자리) | 표, 통계 타일, 차트, 운영자 콘솔 전체 |
| 운영자 콘솔의 실시간 띠 한 줄, 토스트 | 다가오는 날짜의 목록, 검색 결과, 내 예약, 관심 자리 |

- 보드는 잉크가 기본이지만 **같은 행이 종이 위에서도 동작합니다**(2.3절의 표면 토큰만 바뀝니다). 다가오는 자리·검색 결과·내 예약은 종이 행을 씁니다. 야외 가독성을 위해 설정에 '밝은 보드'를 두면 보드 컨테이너의 `data-surface`만 `paper`로 바꾸면 됩니다.
- 한 화면에서 잉크가 차지하는 비율은 첫 화면 기준 2/3를 넘기지 않습니다. 레퍼런스 홈은 첫 화면(390×844)의 60%, 화면 전체의 40%입니다.

### 2.4 라임과 빨강을 쓰는 법

**라임은 두 가지 뜻만 가집니다.**

1. 열린 자리·실시간: 플랩 칸, 자리 타일, 좌석도의 빈 자리, 실시간 램프, 심볼·워드마크의 켜진 자리
2. 자리를 움직이는 단 하나의 동작(primary 버튼): 예약하기, 결제하기, 대기 제안 수락, 공석 올리기, 공석으로 다시 올리기

- primary는 **화면에 하나**입니다. 로그인·저장·확인·캘린더 추가처럼 자리가 움직이지 않는 주 버튼은 잉크 solid를 씁니다.
- 선택 상태(칩, 탭, 세그먼트, 사이드바, 날짜 탭의 수 배지)는 라임이 아니라 잉크/종이 반전입니다.
- 목록 행의 hover '예약하기'는 상세로 가는 이동이라 solid입니다.
- 사업자 화면에서 라임은 다시 올리기 버튼, 열린 자리 타일, 실시간 램프뿐입니다. 탭 바 가운데 '공석 올리기'는 잉크 타일입니다.
- 종이 위 라임은 항상 1px 잉크 테두리를 가집니다(`edge` 토큰). 강조 문구에 라임 형광펜을 쓰지 않습니다.

**빨강**

- 보드(잉크) 안에서 빨강은 예약 마감뿐입니다. 60분 이하일 때만 켜지고, 항상 램프 + 남은 시간 글자와 함께 나옵니다.
- 폼 오류·환불 실패·삭제는 종이 위에서만, 경고 아이콘 + 문장과 함께 씁니다. 보드 행 안에는 넣지 않습니다.
- 알림 수 점(dot)은 red 바탕에 흰 숫자입니다.

### 2.5 뱃지 색

**자리가 나온 이유(VacancyOrigin)** — 색을 쓰지 않습니다. 이유는 상태가 아니라 설명이기 때문입니다.

| 값 | 문구 | 모양 |
| --- | --- | --- |
| `CANCELLATION` | 취소석 | 1px 테두리 태그. 종이: stone 테두리 + text-2 글자 / 잉크: on-ink-3 테두리 + on-ink-2 글자 |
| `NO_SHOW` | 노쇼 공석 | 위와 같음 |
| `UNSOLD` | 미판매 | 위와 같음 |
| `REGULAR` | (없음) | 태그를 붙이지 않습니다. 운영자 표에서는 글자로 '일반' |

정의(안내 문구로 그대로 씁니다): 취소석 = 예약한 분이 취소해서 다시 나온 자리 · 노쇼 공석 = 오지 않는 걸로 확인돼 호스트가 다시 내놓은 자리(확인 연락에 답이 없거나 사업자가 불참으로 처리한 경우) · 미판매 = 아직 예약되지 않은 자리.

**예약 상태(BookingStatus)** — 색 + 아이콘 + 글자를 항상 같이 씁니다. 문구는 `src/lib/domain.ts`의 `BOOKING_STATUS_LABEL`을 씁니다.

| 상태 | 문구 | 톤 | 바탕 / 글자 | 아이콘(lucide) |
| --- | --- | --- | --- | --- |
| `CONFIRMED` | 예약 확정 | success | green-tint / green | `Check` |
| `PENDING_PAYMENT` | 결제 대기 | warning | amber-tint / amber | `Clock` |
| `PENDING_APPROVAL` | 승인 대기 | warning | amber-tint / amber | `Clock` |
| `COMPLETED` | 이용 완료 | info | 바탕 없음 + stone 1px / ink | `CheckCheck` |
| `CANCELLED` | 취소됨 | neutral | paper-2 / text-2 | `X` |
| `REJECTED` | 거절됨 | neutral | paper-2 / text-2 | `X` |
| `EXPIRED` | 시간 초과 | neutral | paper-2 / text-2 | `X` |
| `NO_SHOW` | 노쇼 | danger | red-tint / red-deep | `Ban` |
| (환불) `FAILED` | 환불 실패 | danger | red-tint / red-deep | `TriangleAlert` |

> `domain.ts`의 `BOOKING_STATUS_TONE.COMPLETED`는 지금 `neutral`입니다. 취소됨과 모양이 겹치지 않도록 `info`(선 뱃지)로 바꾸는 것을 권합니다. `Tone`의 `brand`는 잉크 바탕 + 종이 글자(실시간·게시 중)입니다.

**회차 상태(사업자 보드)** — 1px 테두리 칩: 종료(글자 muted) · 진행 중 · 공석 게시 중(라임 램프) · 방금 취소 · 미등록(빨간 테두리 + 빨간 램프).

### 2.6 차트 색

- 계열이 하나면 `ink`. 진행 중인 기간(오늘)과 비교 계열(지난달)은 `stone`.
- 범주가 여럿이면 `chart-1 → chart-4`를 **이 순서로** 씁니다. 다섯 번째부터는 '기타'로 묶습니다. 네 색은 종이 바탕에서 명도·채도·색각 이상 구분(인접 쌍 ΔE 9.7 이상)·대비 3:1 검사를 통과한 값입니다.
- 색 채움 안의 글자: chart-1·chart-4 위는 흰색, chart-2·chart-3 위는 ink.
- 라임과 빨강은 차트에 쓰지 않습니다. 상태 색(green·amber·red)을 "네 번째 계열"로 재사용하지 않습니다.
- 차트의 글자(축, 값, 범례)는 계열 색이 아니라 글자색(`fg`, `muted`)입니다.

### 2.7 다크 모드

v1은 라이트 테마만 냅니다. 다만 `data-surface="ink"` 토큰 묶음이 이미 완전한 어두운 세트라서, 다크 모드는 루트를 `ink`로 두고 보드를 `ink-2`로 한 단계 올리는 방식으로 만들 수 있습니다. 그때 정해야 할 값(상태 뱃지의 잉크 위 색 — 후보 `#7FD08A` 10.0:1, `#F2C14E` 11.1:1, 차트 팔레트 재검증)은 아직 확정하지 않았습니다.

### 3.3 숫자 규칙

- `font-feature-settings: "tnum" 1`을 body에 켭니다. 모든 숫자는 고정폭입니다.
- **모노는 회차의 시작·종료 시각과 마감 시각(HH:MM)에만** 씁니다. 금액, 날짜("11.24 화"), 거리, 건수, 남은 시간("2시간 41분"), 예약번호, 상태 표시줄 시각, "15:48 기준" 같은 기준 시각은 Pretendard입니다.
- 모노의 콜론은 한 칸을 그대로 차지합니다. 글자마다 간격을 손보는 처리는 하지 않습니다(전체 자간 −0.05em만).
- 금액은 천 단위 쉼표 + "원". 숫자는 굵게, "원"은 한 단계 작게(행: 18/700 + 13/600). 통화 기호 ₩는 쓰지 않습니다.
- 금액 앞에는 항상 맥락이 붙습니다: 정가면 `정가`(12/600 muted), 가격을 내렸으면 지운 원래 가격(13/500 muted, 취소선).
- 시각은 24시간제 `HH:MM`. 날짜는 `11.24 화` 또는 `11월 24일 화요일`. 오늘·내일은 글자로 씁니다.
- 한글은 `word-break: keep-all`.

### 5.2 모바일 셸(고객)

```
┌ 상태 표시줄 (env(safe-area-inset-top))
├ 헤더 52px: 심볼 28 · 동네 선택(44) · 아이콘 버튼(44)
├ 본문 (좌우 20px, 섹션 사이 8px 띠)
│   홈: 검색 48 → [기다리던 자리] → 종류 칩(2줄) → 날짜 폴더 탭 → 보드(잉크) → 다가오는 자리(종이)
├ (상세) 고정 결제 바: 마감 줄 38 + 버튼 줄 52 + 여백
└ 탭 바 58px + env(safe-area-inset-bottom): 홈 · 검색 · 알림 · 내 예약 · 마이
```

- 본문 아래 여백 = 탭 바(또는 고정 결제 바) 높이 + 안전 영역.
- 상세·예약 흐름에서는 탭 바를 숨기고 고정 결제 바만 둡니다. 고정 결제 바 높이는 약 130px(홈 인디케이터 포함)로, 360×640 기기에서 본문 466px이 남습니다.
- 누르는 영역은 44×44px 이상. 보이는 크기가 작으면(칩 36px, 태그 링크) 투명한 `::after`로 넓힙니다.

### 5.3 데스크톱 셸(고객)

```
┌ 헤더 64px, 아래 1px ink: 로고 조합 · 동네 선택(40) · 검색(400×40) · 내 예약 · 빈자리 알림 · 관심 자리 · [사업자 센터 ↗] · 프로필

│   묶음 라벨 12/700 + 항목 36px(14/600)         ├ 본문 패딩 24px 28px 32px

│   맨 아래: 운영자 이름 · 역할 · 2단계 인증     │   통계 타일 4칸(간격 12) → 차트 패널 + 처리할 일(340px) → 필터 → 표 → 페이지
```

콘솔에서 잉크는 실시간 띠 한 줄뿐입니다. 표·차트·폼은 모두 종이 위에 둡니다.

## 6. 컴포넌트

레퍼런스의 컴포넌트 시트(`data-frame="components"`)와 1:1입니다. 파일 위치는 `02-architecture.md`의 디렉터리 규칙을 따릅니다(`ui/` = 프리미티브, `shared/` = 도메인 공통).

### 6.1 버튼 — `ui/Button`

| 변형 | 바탕 / 글자 / 테두리 | hover | 누름 | 쓰임 |
| --- | --- | --- | --- | --- |
| `primary` | lime / ink / inset 1px `edge` | lime-hover | lime-press + 1px 내려감 | 자리를 움직이는 동작. 화면에 하나 |
| `solid` | fg / bg (종이: 잉크 바탕, 잉크: 종이 바탕) | ink-3 (잉크 위 paper-2) | ink-line-2 (잉크 위 paper-3) | 그 밖의 주 버튼 |
| `line` | 투명 / fg / inset 1px fg (잉크 위 ink-line-2) | surface | surface-3 | 보조 동작 |
| `ghost` | 투명 / fg / 없음, 좌우 패딩 10 | surface | surface-3 | 낮은 우선순위("직접 채울게요", "나중에") |
| `danger` | 투명 / urgent / inset 1px urgent | red-tint | red-tint + 2px 테두리 | 취소·삭제의 첫 단계 |
| `danger-solid` | red / 흰색(5.6:1) | — | — | 확인 다이얼로그의 최종 실행만 |

| 크기 | 높이 | 좌우 패딩 | 글자 | 쓰임 |
| --- | --- | --- | --- | --- |
| `lg` | 52px | 20px | 18 / 800, −0.03em | 고정 결제 바, 카드의 주 동작 |
| `md` | 44px | 16px | 15 / 700, −0.02em | 기본 |
| `sm` | 36px | 12px | 13 / 700 | 데스크톱 전용. 모바일에서는 `::after`로 44px 확보 |
| 아이콘 버튼 | 44×44px | — | 아이콘 24 | 헤더, 닫기, 관심 |

- 공통: 모서리 6px, 아이콘과 글자 간격 6px, 아이콘은 글자 앞(이동을 뜻하는 꺾쇠만 뒤), 한 줄(`white-space: nowrap`).
- 포커스: `outline: 2px solid var(--focus); outline-offset: 2px`.
- 비활성: 바탕 surface-3, 글자 stone, 테두리 없음, `cursor: not-allowed`. ghost는 바탕 없이 글자만 흐리게. 왜 못 누르는지 가까운 곳에 글로 적습니다.
- 진행 중: 글자 앞에 자리 타일 3개(7×7px, 간격 3, 모서리 2)가 차례로 켜지고, 문구가 "예약하는 중"처럼 바뀝니다. `aria-busy="true"`, 버튼 폭 고정, 다시 누르기 막음.
- 고정 결제 버튼은 무엇을 예약하는지 이름을 답니다: `남성 자리 · 39,000원 예약하기`(앞부분 14/700, 불투명도 80%).

**자리 타일(핍)**

| --- | --- |
| 6자리 이하 | 한 줄 |

| 상태 | 모양 |
| --- | --- |
| 찬 자리 | `seat` 색 채움(잉크 위 stone, 종이 위 ink) |
| 열린 자리 | lime 채움(종이 위에서는 inset 1px ink) |
| 방금 취소 · 미등록(사업자) | 빈 칸 + inset 1.5px urgent |
| 판매 안 함(보류) | 빈 칸 + inset 1.5px subtle |
| 끝난 회차 | ink-line-2 채움 |

타일 8×8px, 간격 2px, 모서리 2px. 사업자 보드는 11×11px, 간격 3px. 옆에는 `8자리 중`처럼 정원을 글자로 적습니다. 잉크 위에서 찬 자리와 열린 자리는 명도 대비 3.2:1이라 색각 이상에서도 구분됩니다. 타일 묶음에는 `aria-hidden`을 주고 의미는 플랩과 글자가 전합니다.

**좌석도(상세 커버)** — 좌석 데이터로 그립니다. 손으로 그린 그림이 아닙니다.

| 조건 | 그림 |
| --- | --- |
| 유형 2개 · 12자리 이하 | 테이블 막대 양쪽에 유형별 한 줄. 왼쪽에 12 / 600 라벨(여·남) |
| 유형 1개 · 12자리 이하 | 테이블 둘레에 위·아래로 고르게 |
| 1타임(시술·코트·객실 1개) | 타일 하나, 테이블 없음 |
| 13–24자리 | 10칸 격자(10px 타일, 간격 3px) |
| 25자리 이상 | 막대 + 숫자 |

### 6.6 플랩 타일 · 램프

**플랩 타일** `shared/SessionTime` — **회차 시작 시각이 주인공인 화면에서만, 화면에 한 번**: 자리 상세 커버와 예약 패스. 실시간 시계, 카운트다운, 통계, 목록에는 쓰지 않습니다.

- 타일 44×68px(380px 미만 38px 폭), 모서리 6px, 간격 4px
- 바탕: 위 반쪽 `tile-top`, 아래 반쪽 `tile-bottom`(50% 지점에서 끊기는 2단 색). **가운데를 가로지르는 선은 없습니다.** 숫자가 잘려 보이지 않게 색 차이만 둡니다
- 좌우 가운데에 4×6px 힌지 홈(ink)
- 숫자: Chivo Mono 700, 44px / 68px, 종이색. 콜론은 6×6px 네모 둘(간격 12px, 폭 10px)
- `role="img"` + `aria-label="시작 19시 30분"`

**램프**: 지름 8px 원. 실시간 = lime + 3px 헤일로(`rgb(200 245 58 / .22)`), 종이 위에서는 헤일로 대신 1.5px ink 링. 마감 = `urgent` 색 + 같은 색 24% 헤일로. 램프는 항상 글자 옆에 붙습니다("15:48 기준 · 실시간", "12분 남음").

### 6.7 예약 마감 표시 — `shared/Deadline`

| 남은 시간 | 표시 | 색 |
| --- | --- | --- |
| 60분 초과 | `예약 마감 18:30` (+ 넓으면 `2시간 41분 남음`) 분 단위 | 중립(fg / muted) |
| 60분 이하 | 빨간 램프 + `예약 마감 16:00` + `12분 남음` + **마감선** | urgent, 700 |
| 30분 이하(행) | 시각 열의 진행 시간 자리가 `● 12분 남음`으로 바뀜 | urgent, 700 |
| 10분 이하 | `04:51 남음`(분:초) | urgent, 700 |
| 마감 뒤 | `예약이 마감됐어요` | muted |

**마감선**: 행(또는 마감 줄)의 아래 선 위에 왼쪽부터 놓이는 2px `urgent` 선. 길이 = `남은 분 ÷ 60`(최소 4%). 시간이 줄수록 짧아집니다. 선만으로 뜻을 전하지 않고 항상 "12분 남음" 글자가 함께 있습니다. 행을 나누는 선 자체의 색과 굵기는 바뀌지 않습니다.

고정 결제 바의 마감 줄: 높이 38px, 13 / 600, `Clock` 16(60분 이하면 빨간 램프) + `예약 마감` + 모노 시각, 오른쪽에 `2시간 41분 남음`.

### 7.1 아이콘

`lucide-react`를 씁니다. 24 격자, 둥근 끝·둥근 이음. 화면에서 보이는 획이 약 1.6px로 같도록 크기마다 `strokeWidth`를 달리합니다.

## 8. 말투

### 8.1 기준

- 해요체로 짧게. 한 문장에 한 가지만. 명사로 끝나는 딱딱한 문장("~완료", "~불가")보다 풀어 쓴 문장.
- 주어는 고객입니다. "예약이 접수되었습니다"가 아니라 "자리를 잡았어요".
- 숫자와 시각은 구체적으로. "곧 마감"이 아니라 "12분 뒤 예약 마감".
- 왜 그런지, 다음에 무슨 일이 일어나는지를 같이 말합니다("취소로 나온 자리라 정가 그대로예요", "대기 2명에게 먼저 알리고, 10분 뒤 모두에게 공개돼요").

- 낱말: 자리(좌석·재고 ✕), 호스트·진행하는 곳(판매자 ✕), 빈자리 알림(웨이팅 ✕), 공석(사업자 화면에서만), 예약 마감(판매 종료 ✕), 정가.

### 8.3 있는 그대로의 긴박함

1. **남은 수는 실제 값만.** 화면의 모든 남은 자리 수는 `capacity − reserved`입니다(아키텍처 6.1). 올림·내림·"몇 자리 안 남음" 같은 뭉개기를 하지 않습니다.
2. **기준 시각을 밝힙니다.** 보드와 자리 선택에는 "15:48 기준"을 적습니다. 폴링이 끊기면 램프를 끄고 "연결이 끊겼어요 · 15:48 기준"으로 바꿉니다.
3. **마감은 실제 예약 마감 시각.** 60분 넘게 남았으면 중립색으로 시각만. 빨강·마감선·분:초는 6.7절의 문턱에서만 켜집니다.
4. **초 단위로 깜빡이는 타이머를 쓰지 않습니다.** 10분 이하에서만 분:초를 글자로 보여줍니다.
5. **정가는 정가라고.** 금액 앞에 늘 `정가` 또는 지운 원래 가격이 있습니다. 지운 가격은 호스트가 이 회차에 실제로 받던 가격일 때만. 할인율(%) 배지는 만들지 않습니다.
6. **사람 수로 압박하지 않습니다.** "N명이 보고 있어요", "방금 N명이 예약" 같은 문구는 없습니다. 대기 수(`대기 3명`)는 순번을 알려주는 정보라서 보여줍니다.
7. **홀드 시간은 약속입니다.** "15:58까지 잡아뒀어요"라고 적은 시각까지는 실제로 자리가 잡혀 있어야 합니다.
8. **첫 화면에 총액.** 상세의 고정 버튼 금액은 수수료를 포함해 실제로 결제되는 금액입니다. 미리 선택된 추가 옵션은 없습니다.
9. **이유는 사실대로.** 태그(취소석·노쇼 공석·미판매)는 회차의 `origin` 값 그대로입니다. 전환을 위해 바꿔 달지 않습니다.

## 9. 접근성 체크리스트

**대비**

- [ ] 본문·보조 글자 4.5:1 이상(2.1절 표의 조합만 사용). 종이 위 보조 글자는 `text-2`, 잉크 위는 `on-ink-2`까지. `on-ink-3`·`stone`은 글자에 쓰지 않음
- [ ] 컨트롤 경계·아이콘·자리 타일 3:1 이상(입력 테두리 stone, 찬 자리 stone/ink, 열린 자리 lime + 테두리)
- [ ] 라임은 글자색으로 쓰지 않음. 종이 위 라임 채움에는 1px 잉크 테두리
- [ ] red를 paper-2 위에 놓을 때는 13px 700 이상 또는 red-deep

**색만으로 전하지 않기**

- [ ] 남은 자리는 플랩의 글자로, 타일은 보조
- [ ] 상태 뱃지는 아이콘 + 글자, 마감은 램프 + 글자, 오류는 아이콘 + 문장
- [ ] 선택 상태는 반전 + `aria-pressed` / `aria-selected` / `aria-checked` / `aria-current`
- [ ] 환불 막대는 채움·빗금·빈 칸으로 구분하고 각 조각에 글자

**키보드와 포커스**

- [ ] 모든 동작을 키보드로. 탭 순서는 읽는 순서
- [ ] `:focus-visible`에 2px 포커스 링(종이 위 ink, 잉크 위 paper, 간격 2px). `outline: none`만 두지 않음
- [ ] 시트·다이얼로그: 포커스 가두기, Esc로 닫기, 닫으면 연 버튼으로 돌아감
- [ ] 데스크톱 표 행: 제목 링크에 포커스가 가면 행 전체가 hover와 같은 모습(`:focus-within`)

**누르는 영역**

- [ ] 모바일에서 44×44px 이상(칩·작은 버튼·글자 링크는 `::after`로 확장). 인접한 영역끼리 겹치지 않음
- [ ] 수량·체크인처럼 연달아 누르는 버튼 사이는 8px 이상

**구조와 이름**

- [ ] 화면마다 `h1` 하나, 구획 제목은 `h2`, 행 제목은 `h3`
- [ ] 목록 보드와 운영자 목록은 `<table>` + `<th scope>` + `<caption>`(가려도 됨) + `aria-sort`
- [ ] 날짜 탭 `role="tablist"`/`tab`/`tabpanel`, 자리 선택 `role="radiogroup"`/`radio`, 검색 `role="search"`
- [ ] 아이콘 버튼 `aria-label`. 좌석도·플랩 타일·차트 `role="img"` + 설명. 꾸밈 타일·커버 `aria-hidden`
- [ ] 폼: `<label>` 연결, 오류는 `aria-invalid` + `aria-describedby`, 제출 실패 시 첫 오류로 포커스
- [ ] 시각은 `<time datetime>`으로 감싸기

**움직임과 실시간**

- [ ] `prefers-reduced-motion`에서 플랩 넘김·맥박·스켈레톤 애니메이션 끔
- [ ] 남은 시간 글자는 `aria-live="off"`. 10분·5분·1분 시점과 마감 시점에만 가려진 `aria-live="polite"` 영역으로 알림
- [ ] 남은 자리 수가 바뀌면 같은 영역으로 한 번만 알림("남성 자리가 마감됐어요")
- [ ] 토스트는 `role="status"`(오류는 `alert`), 4초 뒤 사라져도 내용은 알림함에서 다시 볼 수 있음
- [ ] 홀드 만료처럼 시간 제한이 있는 단계는 만료 전에 알리고, 만료되면 무슨 일이 일어났는지 문장으로 설명

**글자와 확대**

- [ ] 최소 12px, 본문 15px, 입력 16px. 한글 `word-break: keep-all`

- [ ] 360px 폭에서 넘침 없음(레퍼런스 `#w360`으로 확인)

- 시각·금액 표시는 `src/lib/time.ts`·`src/lib/money.ts`만 씁니다. 컴포넌트에서 직접 포맷하지 않습니다.
- 남은 자리·마감·대기 수는 서버가 준 값을 그대로 그립니다. 클라이언트에서 추정하거나 보정하지 않습니다.
- 표면은 감싸는 쪽이 정합니다. 컴포넌트 안에서 `bg-ink`·`text-paper`를 직접 쓰지 말고 `bg-bg`·`text-fg`·`border-line`을 씁니다. 원시색을 직접 쓰는 곳은 라임 채움(`bg-lime text-ink`), 상태 뱃지, 플랩 타일, 로고뿐입니다.

**레퍼런스에 아직 그려지지 않은 것** — 명세만 있고 화면은 없습니다. 만들 때 이 문서의 토큰·컴포넌트로 조립합니다.

- 사업자 센터의 데스크톱 화면(5.4), 다크 모드(2.7), 전체 화면 지도 보기, 상세의 사진 갤러리 구획(7.3)
- 로그인·가입·본인 인증, 결제 단계, 내 예약 목록, 알림함, 검색 결과, 마이
- 플랩 넘김 등 모션의 실제 구현(4.5의 값으로)
- 실제 기기·야외 밝기에서의 가독성 확인과 대상 고객 사용성 평가는 하지 않았습니다. 잉크 보드를 기본으로 둘지는 그 결과를 보고 다시 정합니다('밝은 보드' 전환은 2.2절대로 준비돼 있습니다).
